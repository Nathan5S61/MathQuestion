# MathematicsQuestions

Collection of solved mathematics problems with full derivation notes.  
Materials cover calculus, asymptotic analysis and algebraic equations, with multiple solving approaches for cross‑verification.  

## Contents
### Asymptotic Limit Exercise
Solves an asymptotic limit with factorial and triangular‑number notation.  
- Method 1: Stirling's asymptotic approximation  
- Method 2: Riemann‑sum integral transformation  

### General Cubic Equation (Cardano's Method)
Full algebraic derivation for cubic polynomial roots.  
Quadratic completing‑the‑square is reviewed as preliminary background.  
Derivation stages:  
1. Eliminate quadratic term by variable substitution  
2. Solve depressed cubic using cube‑root manipulation and complex cube roots of unity  
3. Substitute back to obtain closed‑form roots for original cubic equation  

Each problem includes LaTeX source files and markdown overview notes.
