# Problem Introduction
This document walks through the full algebraic derivation for general cubic equations using Cardano's method.

The derivation follows three major stages.  
It first eliminates the quadratic term via variable substitution to get a depressed cubic form.  
Next it solves the simplified cubic equation, making use of cube‑root manipulation and complex cube roots of unity. 
Finally, results are converted back to produce closed‑form roots for the original general cubic polynomial.
